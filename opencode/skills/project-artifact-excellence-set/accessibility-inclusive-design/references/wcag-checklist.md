# WCAG Checklist

Use this checklist to claim WCAG 2.1 AA with evidence per criterion.

## Perceivable

- Provide text alternatives for non-text content on all meaningful images and icons.
- Caption prerecorded video and provide transcripts for audio-only content.
- Meet 4.5 to 1 contrast for normal text and 3 to 1 for large text and essential graphics.
- Allow 200% zoom without loss of content or function on scoped pages.
- Never convey meaning by color alone; add text or icon cues.

## Operable

- Make all functions operable by keyboard with no traps.
- Provide skip links to main content on pages with navigation.
- Give users enough time with adjustable limits or pause controls.
- Avoid flashing content more than 3 times per second.
- Keep navigation order meaningful and headings correctly nested.

## Understandable

- Set page language programmatically and flag language changes inline.
- Keep labels, instructions, and navigation consistent across the product.
- Identify input errors in text and suggest correction where safe.
- Require confirmation or reversible submit for legal and financial actions.
- Write at a reading level that matches the audience with defined terms.

## Robust

- Use valid markup with correct nesting for scoped templates.
- Expose correct name, role, and value for all custom controls.
- Keep status messages programmatically determinable without stealing focus.
- Test with at least one desktop and one mobile screen reader.
- Record tool, version, and pass or fail evidence for each criterion.

## Evidence and Severity

- Log page, component, criterion, result, and assistive technology per check.
- Mark any barrier that blocks task completion as critical with fix date.
- Recheck fixed items with the same tools and user flows.
- Add regression tests for every critical barrier found.
- Schedule full re-audit within 90 days of certification.
