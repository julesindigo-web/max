# Glossary — v2.0.0

- **Skill**: single modular capability package (SKILL.md + scripts/references/assets).
- **Plugin**: skill with declared extension/integration contracts.
- **Skill set**: coherent collection delivering higher-order capability with manifest, contracts, traceability, and gates.
- **Evidence state**: Verified / Inference / Unknown-Untested / Contradicted / Not-applicable; independent from severity.
- **Severity basis**: observed impact, mandatory-control gap, conditional risk, limited impact, or improvement-only.
- **TPR/FPR**: true-positive rate TP/(TP+FN); false-positive rate FP/(FP+TN).
- **Candidate test set**: frozen prompts with expected labels; not runtime observations.
- **Runtime run**: executing the frozen set in the target runtime with activation logs.
