# RACI — v2.0.0

| Activity | Responsible | Accountable | Consulted | Informed |
|---|---|---|---|---|
| Audit execution | Auditor agent | Audit quality reviewer | Domain owners | Release approver |
| Feedback event normalization | Auditor agent | Skill-set maintainer | Target skill owner | Reviewer queue |
| Skill change proposal | Assigned agent/reviewer | Skill owner | Human-factors evaluator | Release approver |
| Release gate + packaging | Release evaluator | Release approver | Security reviewer | Consumers |
| Runtime trigger/task measurement | Evaluation lead | Release approver | Skill authors | Stakeholders |

All Critical/Major findings need an owner and a review date; accepted risks need explicit authorization.
