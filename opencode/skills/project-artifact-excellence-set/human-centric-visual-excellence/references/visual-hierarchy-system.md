# Visual Hierarchy System

Build spatial harmony with a token-driven hierarchy system.

## Set Modular Type Scale

- Use a 1.25 ratio scale with steps at 12, 14, 16, 20, 25, 31, and 39px or nearest tokens.
- Assign one size per role: body, label, heading, display. Never improvise sizes.
- Hold body at 16px or larger with line height 1.5 or higher.
- Limit each view to 3 type sizes plus display where justified.
- Test legibility at 100% and 200% zoom on desktop and mobile.

## Space With Ratio and Grid

- Base spacing on an 8px grid with golden-ratio steps near 8, 13, 21, 34, and 55px.
- Use generous whitespace to group related elements and separate sections.
- Keep section spacing at least twice the inner element spacing.
- Align controls, text, and media to shared baselines and columns.
- Audit for orphaned gaps and uneven rhythm before handoff.

## Direct Attention

- Give the primary action the strongest weight, size, or color in the view.
- Demote secondary actions to quiet styles with equal tap targets.
- Place primary actions where the eye lands after the headline.
- Remove banners, badges, and bold treatments that compete with the goal.
- Confirm first-click choice with at least 5 task walkthroughs.

## Assign Color Roles

- Define roles for background, surface, text, border, accent, success, warning, and danger.
- Use one accent color for interactive elements across the product.
- Meet AA contrast for text and essential controls in every theme.
- Avoid color-only meaning by adding icons or text cues.
- Document palette trust notes so future choices stay calm and premium.

## Disclose Progressively

- Show only the fields and options required for the current step.
- Collapse advanced settings behind clearly labeled expanders.
- Preserve context with headers, progress, and summary on staged flows.
- Keep undo, back, and save states visible during multi-step tasks.
- Measure task time and error rate before and after simplification.
